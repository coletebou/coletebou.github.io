Sheet G-002General notes, legend and index

General notes

  1. Find the real constraint. Frameworks change. The load path does not. Trace it before writing code.
  2. Make state inspectable. If the operator cannot see it, it is not done.
  3. Fail inside the boundary. An ambiguous route is rejected, never guessed.
  4. Verify after "done". Passing tests are a submittal, not an inspection. Run the real flow end to end.
  5. Ship, observe, repair. Deployment starts the feedback loop. It does not end it.
  6. Private and employer work is shown for reference only (N.I.C.). Where a live surface exists, the sheet links to it instead of the code.
  7. All activity is measured in commits per week unless noted otherwise. Contours are surveyed nightly from GitHub.
